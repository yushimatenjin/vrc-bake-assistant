# 0.1.7 マテリアル置換メモ

GLB/glTFastや購入アセットのMaterialで、ライトベイク後に暗い・明るさが馴染まない・反射や発光が意図通りにならない場合のために、Bake対応Materialの確認・複製・置換機能を追加しました。

## 基本方針

元Materialは編集・削除しません。`Assets/VRCBakeAssistant/GeneratedMaterials` にStandard Shader版の複製を作り、RendererのMaterial割り当てだけを差し替えます。

## まず使う流れ

1. Hierarchyで試したい床・壁・家具を選択します。
2. 「選択RendererのMaterialだけ更新」を押します。
3. Unlit / glTF / 特殊Shader が「要確認」として表示されます。
4. 「選択Rendererだけ置換」を押します。
5. 見た目を確認し、必要ならBakeを実行します。

## 注意

透明、ガラス、Toon、特殊Shaderは見た目が変わりやすいです。いきなりシーン全体に使わず、選択範囲で試してください。

GLBのMetallic/RoughnessテクスチャはUnity StandardのMetallicGlossMapとチャンネル構成が違う場合があるため、0.1.7では完全変換ではなく、BaseColor、MainTex、Normal、Emission、基本的なMetallic/Smoothness値のコピーを中心にしています。
