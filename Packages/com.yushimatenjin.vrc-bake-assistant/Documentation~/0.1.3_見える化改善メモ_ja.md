# VRC Bake Assistant 0.1.3 見える化改善メモ

## 目的

0.1.3では、ベイク作業を「ボタンを押す」だけでなく、今のシーンの状態を見て判断できる方向へ寄せました。

特に改善したい体験は次の3つです。

- どのRendererがBake対象なのか分からない
- どのLightがBakeに使われるのか分からない
- Light Probeの置く範囲や数がイメージしづらい

## 追加した主な機能

### 1. 練習シーンのHierarchy整理

練習シーン生成時、以下の親オブジェクトに分けます。

```text
VRC Bake Assistant Generated
└─ 00_SampleScene_練習シーン全体
   ├─ 00_Guide_原点と説明
   ├─ 01_BakeTargets_焼く床壁家具
   ├─ 02_NotBaked_動く物と確認用
   ├─ 03_Lights_ベイク用ライト
   ├─ 04_Probes_LightProbeとReflectionProbe
   └─ 05_Camera_確認用
```

### 2. Renderer一覧

`Renderer一覧：Bake対象をポチポチ切り替える` を追加しました。

一覧では以下を確認できます。

- Bake対象ON/OFF
- Reflection Probe Static ON/OFF
- 未参加だけ表示
- UV2不足の目安
- 動的っぽい名前の警告
- オブジェクト選択ボタン

これにより「この床はBakeする」「このアバター高さ確認用カプセルはBakeしない」のように、手で確認しながら切り替えできます。

### 3. おすすめ自動設定

`おすすめ自動設定：静止物っぽいMeshRendererをON、動く物っぽいものをOFF` を追加しました。

これは完全自動の正解ではありません。あくまで初期値を作るための補助です。
最後は必ずRenderer一覧で確認する設計です。

### 4. Light一覧

`Light一覧：Bakeに使うライトを確認する` を追加しました。

一覧では以下を確認できます。

- LightのON/OFF
- Baked / Mixed / Realtimeの切り替え
- Directional / Area / Point / Spotの種類
- Bakeに使うライトか、実行時のみのライトか
- 前回Bakeメモから見て新規・変更されたライトか

### 5. 前回Bakeメモ

UnityのLighting Data Assetから「前回Bake時にどのライトが使われたか」を安全に読む用途の公開APIは限定的です。
そのため、このツールではBake完了時に独自のJSONを保存します。

```text
Assets/VRCBakeAssistant/Reports/LastBakeSnapshot.json
```

保存する内容は、Baked/Mixedライトの種類、BakeType、強さ、色、位置、回転などです。
次回診断時に、今のライトとの差分を見て「新規/変更/削除」を表示します。

外部のLightingウィンドウでBakeした場合は、`今のライト状態を前回Bakeメモとして記録` を押すと基準を合わせられます。

### 6. Light Probe範囲の調整

Light Probeの配置範囲を以下で調整できます。

- 自動範囲
- 手動Center / Size
- Probe間隔
- Bounds余白
- 最大Probe数
- Probe数の目安
- 黄色いProbe範囲ガイド

Probeが多すぎると管理しにくいため、最初は3m前後、練習シーンでは200個以下くらいから試す想定です。

## Unity側で確認してほしいところ

- Unity 2022.3.22f1でコンパイルできるか
- 練習シーン作成時にHierarchyが分かりやすいか
- Renderer一覧のON/OFFが意図通りStatic Flagsへ反映されるか
- Light一覧のBakeType切り替えが効くか
- Bake完了後にLastBakeSnapshot.jsonが作成されるか
- 再診断時に新規/変更ライトが出るか
- ALCOMで0.1.3が表示されるか

- Light Probeを部屋ごとに複数Group生成する
- Reflection Probeも部屋単位で複数生成する
- Renderer一覧をCSV/Markdownで出力する
- Before/Afterスクリーンショット撮影機能を追加する
