# 無料配布・紹介動画台本案

## 0:00 - 0:10 問題提起

ナレーション：
「VRChatワールドのライトベイク、毎回どこを触ればいいか分からなくなりませんか？ Lightmap、Light Probe、Reflection Probe、Static設定……見た目に効くのに、設定場所がばらばらです。」

画面：
UnityのLighting画面、Staticチェック、Probeが無いシーンを素早く見せる。

## 0:10 - 0:25 商品紹介

ナレーション：
「VRC Bake Assistantは、ワールド制作者向けのベイク手順ナビです。ボタンを上から順に押すだけで、診断、プリセット適用、Probe生成、ベイク開始まで進められます。」

画面：
Tools > YushimaTenjin > VRC Bake Assistant。

## 0:25 - 0:55 練習シーン

ナレーション：
「まずは練習シーンを作ります。床、壁、ライト、反射確認用の球が自動で配置されるので、ベイクの流れを安全に試せます。」

操作：
練習用シーンを新規作成 → 診断 → プリセット適用。

## 0:55 - 1:35 Probe生成

ナレーション：
「次にLight Probeを作成。アバターや動くオブジェクトが、ワールドの明るさに馴染みやすくなります。Reflection Probeは金属、ガラス、水面の反射確認に便利です。」

操作：
Light Probe Grid作成 → Reflection Probe作成 → Sceneビューで確認。

## 1:35 - 2:10 ベイク

ナレーション：
「試し焼き（早い）で試し焼き、PC向け標準で本番寄り、Quest向け軽量で軽量寄り。BakeAsyncでベイクを開始して、進捗もウィンドウ内で確認できます。」

操作：
Generate Lighting / BakeAsync。

## 2:10 - 2:40 自分のワールドへ

ナレーション：
「自分のワールドでは、まずバックアップ。その後、診断から始めて、Contribute GIやUV2不足を確認します。いきなり本番設定で焼かず、軽いプリセットで絵作りを決めるのがおすすめです。」

画面：
既存ワールドでScan結果と警告を表示。

## 2:40 - 3:00 クロージング

ナレーション：
「難しいベイク設定を、迷わない手順に。VRChatワールドのライト作業を、少しだけ楽にします。」

画面：
Before/After、BOOTH商品ページ、同梱物一覧。
