VRC Bake Assistant

VRChatワールドのライトベイク作業を、上から順に進められる手順にする無料Unityエディター拡張です。

Free MIT License Unity 2022.3 ALCOM / VCC
ALCOM / VCC に追加 vpm.jsonを見る GitHub

ボタンが反応しない場合は、ALCOMの Packages > ADD REPOSITORY から次のURLを追加してください。

https://yushimatenjin.github.io/vrc-bake-assistant/vpm.json

これは何？

Lightmap、Light Probe、Reflection Probe、Static設定、UV2チェック、Bake開始など、Unity内で場所が散らばりがちなライトベイク作業を1つのウィンドウにまとめる補助ツールです。

「まず練習用シーンで流れを覚える」→「自分のワールドを診断する」→「ProbeやLighting Settingsを整える」→「軽い設定で試し焼きする」という進め方を想定しています。

できること

  • ライトベイク用の練習シーンを作成
  • Static / UV2 / Light / Light Probe / Reflection Probe の簡易診断
  • Practice / Quest / PC / Final のLighting Settingsプリセット
  • Light Probe GridとBaked Reflection Probeの生成補助
  • UnityのGenerate Lightingをワンクリックで開始

ALCOMでの導入

  1. ALCOMを開きます。
  2. Packages から ADD REPOSITORY を押します。
  3. https://yushimatenjin.github.io/vrc-bake-assistant/vpm.json を追加します。
  4. 対象プロジェクトの Manage Project から VRC Bake Assistant を追加します。
  5. Unityで Tools > VRC Bake Assistant > Open を開きます。

注意

本ツールはライトベイク作業を補助するエディター拡張です。すべてのワールドで最適な見た目を自動保証するものではありません。使用前にプロジェクトのバックアップを推奨します。

この配布は無料公開前提です。GitHub Pages上のVPMリポジトリJSONとGitHub Releasesのzipを使ってALCOM/VCCに届ける構成です。
