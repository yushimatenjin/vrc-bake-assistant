# 0.1.4 コンパイル修正メモ

## 修正内容

Unity 2022.3.22f1で以下のエラーが出る問題を修正しました。

```text
error CS1503: Argument 1: cannot convert from 'UnityEngine.GUIContent' to 'int'
error CS1503: Argument 2: cannot convert from 'int' to 'string[]'
error CS1503: Argument 3: cannot convert from 'string[]' to 'int[]'
error CS1503: Argument 4: cannot convert from 'int[]' to 'UnityEngine.GUILayoutOption'
```

原因は `EditorGUILayout.IntPopup` に `GUIContent` ラベルと `string[]` の表示名配列を混ぜて渡していたことです。
Unity 2022.3ではこの組み合わせだとoverload解決に失敗するため、文字列ラベル版の `IntPopup` に変更しました。

## 変更箇所

`Packages/com.yushimatenjin.vrc-bake-assistant/Editor/VRCBakeAssistantWindow.cs`

旧:

```csharp
reflectionProbeResolution = EditorGUILayout.IntPopup(new GUIContent("Reflection Probe解像度", "..."), reflectionProbeResolution,
    new[] { "64", "128", "256", "512" },
    new[] { 64, 128, 256, 512 });
```

新:

```csharp
reflectionProbeResolution = EditorGUILayout.IntPopup("Reflection Probe解像度", reflectionProbeResolution,
    new[] { "64", "128", "256", "512" },
    new[] { 64, 128, 256, 512 });
EditorGUILayout.HelpBox("反射の解像度です。まずは128、重い場合は64。", MessageType.None);
```

## UdonSharpのエラーについて

UdonSharpの以下のログは、VRC Bake AssistantのC#コンパイルエラーによってUnity全体のコンパイルが止まり、UdonSharp側のscene upgradeが実行できないために出ている連鎖ログです。

```text
[UdonSharp] C# scripts have compile errors, cannot run scene upgrade.
```

まず本パッケージのC#コンパイルエラーを解消してください。
