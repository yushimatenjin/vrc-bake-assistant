# 0.1.5 Toolsメニュー整理メモ

## 原因

0.1.4までは互換用として、同じウィンドウを開く `MenuItem` を複数登録していました。

```csharp
Tools/YushimaTenjin/VRC Bake Assistant
Tools/VRC Bake Assistant/ライトベイク手順を開く
Tools/VRC Bake Assistant/Open
```

このため、Unityの `Tools` メニュー上では別々のツールが混在しているように見えていました。

## 修正

0.1.5では入口を次の1つだけに整理しました。

```text
Tools > YushimaTenjin > VRC Bake Assistant
```

## まだ2つ出る場合

次のどれかがプロジェクト内に残っている可能性があります。

```text
Assets/VRCBakeAssistant/Editor/VRCBakeAssistantWindow.cs
Assets/VRCBakeAssistant/Editor/
Packages/com.peraperavrc.vrc-bake-assistant/
Packages/com.yushimatenjin.vrc-bake-assistant/ の古いEmbeddedコピー
```

VPM版を使う場合は、基本的に次の1つだけが残っていれば大丈夫です。

```text
Packages/com.yushimatenjin.vrc-bake-assistant/
```

Projectビューで `VRCBakeAssistantWindow` を検索し、同名スクリプトが複数ないか確認してください。
