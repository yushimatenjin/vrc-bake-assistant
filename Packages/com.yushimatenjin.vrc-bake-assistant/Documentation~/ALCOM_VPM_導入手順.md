# ALCOM / VPM 導入手順

## Repository URL

```text
https://yushimatenjin.github.io/vrc-bake-assistant/vpm.json
```

## ALCOMで入れる

1. ALCOMを開きます。
2. `Packages` を開きます。
3. `ADD REPOSITORY` を押します。
4. 上記のRepository URLを追加します。
5. 対象プロジェクトの `Manage Project` を開きます。
6. `VRC Bake Assistant` の `+` を押して追加します。
7. Unityを開き、`Tools > VRC Bake Assistant > Open` を確認します。

## vcc:// URL

```text
vcc://vpm/addRepo?url=https%3A%2F%2Fyushimatenjin.github.io%2Fvrc-bake-assistant%2Fvpm.json
```

ブラウザから開けない環境では、手動でRepository URLを追加してください。
